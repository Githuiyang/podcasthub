# 03 — Web 端用户流程

> 状态：已完成
> 最后更新：2026-04-15

## 普通访客流程

### 流程 A：从地图发现

1. 进入首页 → 自动选中录音室数量最多的城市 → 看到全屏地图 + 该城市录音间 markers
2. 鼠标悬停 marker → hover 预览卡（名称 + 地址 + 价格）
3. 点击 marker → 打开双 Tab 详情弹窗（信息 Tab 默认）
4. 切换到图片 Tab → 查看封面和作品图片
5. 点击弹窗内链接 → 进入独立详情页（完整信息 + 交通 + 预约）

### 流程 B：从列表页筛选比较

1. 导航栏点击"录音间" → 进入列表页
2. 选择城市 → 筛选该城市录音室
3. 输入搜索词 → 按名称/地址过滤
4. 点击录音室卡片 → 进入详情页
5. 详情页查看交通信息 → 判断是否方便到达

### 流程 C：提交录音室

1. 导航栏"添加我的录音室"（全站主入口）或 首页 FAB"收录录音室"（弱入口）或 列表页"提交录音室信息" → 进入征集页
2. 查看提交流程说明
3. 点击飞书表单链接 → 在浏览器中打开并填写
4. 提交后等待审核上线

### 流程 D：反馈

1. 导航栏点击"反馈" → 打开 FeedbackModal
2. 填写称呼 + 反馈详情
3. 点击提交 → 飞书 Webhook 推送通知

### 流程 D2：录音室信息反馈

1. 录音室详情页底部或首页弹窗底部点击"信息有误？告诉我们" → 打开 FeedbackModal（自动显示录音室名称）
2. 填写反馈详情（placeholder 提示：地址、价格、预约方式或营业状态是否有变化？）
3. 点击提交 → 飞书 Webhook 推送通知（橙色标题，包含录音室 ID/名称/来源）

### 流程 E：查看剪辑师 / 商务

1. 导航栏点击"剪辑师" → 进入人才墙列表页（4 列人物卡，居中布局，slate 统一色系）
2. 浏览人物卡片 → 点击进入人物主页（居中布局，border 分隔各区块）
3. 查看擅长方向、专业能力、过往作品、合作评价、报价、联系方式
4. 列表页标题区"商务合作 →"二级链接 → 进入商务列表页
5. 或直接导航栏点击"商务" → 进入商务列表页

## 录音室主理人流程

1. 导航栏"添加我的录音室"或首页 FAB 或列表页"提交录音室信息" → 征集页
2. 填写飞书表单 → 提交
3. 管理员在飞书结果表整理数据
4. 管理员通过飞书同步或变更申请系统审核上线

## 管理员流程

### 流程 F：录音室编辑

1. 导航栏底部隐藏入口 → 管理员登录页
2. 输入密码 → 验证通过 → 进入后台
3. 查看录音室列表 → 按城市筛选
4. 编辑录音室信息 → 保存
5. 软删除失效录音室

### 流程 G：飞书同步

1. 后台 → 飞书同步页
2. 点击"拉取" → 从飞书结果表拉取最新数据
3. 查看 diff → 确认新增/更新/删除
4. 点击"同步上线" → 写入 studios 表

### 流程 H：变更审批

1. 后台 → 变更审批页
2. 查看待审批列表
3. 点击某条 → 查看 diff 详情
4. 批准或拒绝
5. 批准后自动同步写入 studios 表
