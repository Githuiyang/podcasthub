# 08 — Web 端设计系统

> 状态：已实现
> 最后更新：2026-04-15

## 设计原则

1. **地图即首页**：Web 端首页是全屏地图，不是列表页
2. **信息清晰**：录音室名称、地址、价格为最高优先级
3. **克制展示**：通过 `studioPresentation.ts` 去重，避免信息重复
4. **深色主题**：主色调 #111827（gray-900），强调色与 Tailwind gray 色阶一致

## 色彩

| 用途 | 色值 | Tailwind | 说明 |
|---|---|---|---|
| 主色 | `#111827` | gray-900 | 标题、导航、CTA |
| 次要文字 | `#6b7280` | gray-500 | 副标题、辅助文字 |
| 辅助灰 | `#9ca3af` | gray-400 | 占位、hint |
| 背景 | `#f9fafb` | gray-50 | 页面底色 |
| 卡片白 | `#ffffff` | white | 卡片、弹窗背景 |
| 价格标签 | `#f0fdf4` | green-50 | 价格 chip 背景 |
| 边框 | `#e5e7eb` | gray-200 | 卡片边框 |
| 强调色 | `#f59e0b` | amber-500 | 地图 marker、CTA |

## 间距

- 页面内边距：响应式（桌面 `max-w-7xl mx-auto px-4`）
- 卡片内边距：`p-4` ~ `p-6`
- 区块间距：`gap-4` ~ `gap-6`

## 圆角

- 卡片：`rounded-lg` ~ `rounded-xl`
- 按钮：`rounded-lg`
- 标签：`rounded-full`（胶囊）

## 字号

| 用途 | Tailwind | 说明 |
|---|---|---|
| 页面标题 | `text-2xl` ~ `text-3xl` | 详情页标题 |
| 卡片标题 | `text-lg` ~ `text-xl` | 列表卡片 |
| 正文 | `text-base` ~ `text-sm` | 正文、描述 |
| 辅助文字 | `text-xs` ~ `text-sm` | 标签、hint |

## 组件风格

### 导航栏

- 桌面：顶部水平导航，四入口（首页 / 录音间 / 剪辑师 / 商务）+ "添加我的录音室"按钮 + 反馈
- 移动：顶部"添加录音室"+ 反馈 + 底部四入口 Tab（首页 / 录音间 / 剪辑师 / 商务）
- 当前稳定版本为四入口导航（2026-04-15 曾短暂改为双 Tab 后已回滚）

### 提交录音室入口策略

- **全站主入口**：导航栏"添加我的录音室"黑按钮（桌面 + 移动端），所有页面可见
- **首页弱入口**：地图右上角 FAB — 轻量灰色"+"按钮（`bg-white/90 border-slate-200`），hover/点击展开"收录录音室"描边按钮
- **列表页辅助入口**：录音间列表页头"提交录音室信息"描边按钮（`border-slate-200`）
- 不在同一屏出现两个同等强度的提交 CTA

### 城市筛选按钮

- 首页和列表页城市按钮统一按录音室数量降序排列
- 首页默认选中录音室数量最多的城市
- 排序逻辑收敛在 `studioCities.ts`，不在各页面重复实现

### 地图 hover 卡

- 定位在 marker 旁边
- 深色头部（录音室名称）+ 白色内容区
- 展示：地址、价格、开放时间、预约、联系方式
- 归一化展示（`studioPresentation.ts`）

### 双 Tab 详情弹窗

- 居中弹窗（非侧滑）
- 两个 Tab：信息 / 图片
- 默认打开信息 Tab

### 剪辑师人物卡（EditorCard）

- 居中布局（头像 + 姓名 + 标签 + 简介 + 代表作 + 报价）
- 圆角 `rounded-2xl`，阴影 `shadow-sm hover:shadow-md`
- 边框 `border-slate-100`
- slate 统一色系（非 emerald）
- 状态标签：可接单 = emerald，其他 = slate
- 报价显示 `¥xxx/期`

### 剪辑师详情页

- 居中布局 `max-w-2xl mx-auto`
- 区块间 `border-b border-slate-100` 分隔（非 card-section 统一堆叠）
- 头部居中：头像 + 姓名 + 类型 + 状态 + 简介 + 标签
- 统计卡：年经验 / 每期价格 / 作品数
- 使用共享组件：`ContactInfo`、`TagList`

### 商务列表页

- 标题"商务合作"，副标题"播客生态商务对接"
- slate 统一色系

### 反馈弹窗

- `FeedbackModal` 组件
- 最大宽度 `max-w-md`
- 底部含"录音室信息更正"弱链接（仅全站反馈模式）
- 支持 `studioContext` 可选 prop：传入时切换为录音室信息反馈模式
  - 标题：反馈录音室信息
  - 上下文提示条：`正在反馈：xxx录音室`
  - placeholder：`地址、价格、预约方式或营业状态是否有变化？`
  - 成功文案：`我们会尽快核实并更新录音室信息`

### 录音室信息反馈入口

- 详情页底部：`text-xs text-slate-300`，分隔线下方居中
- 首页弹窗底部：`text-[11px] text-slate-300`，操作按钮下方居中
- 视觉弱于主 CTA（预约/查看详情），不抢主流程
- 点击打开 FeedbackModal，自动带上 studio_id/studio_name/source

## 与小程序的视觉差异

| 方面 | Web 端 | 小程序端 |
|---|---|---|
| 首页 | 全屏地图 | 轻量地图预览（360rpx） |
| 导航 | 顶部导航栏 | TabBar（首页/录音室） |
| 详情 | 双 Tab 弹窗 + 独立页 | 单页滚动 |
| 颜色单位 | Tailwind class | rpx/px |
| 字号单位 | rem | px/rpx |
