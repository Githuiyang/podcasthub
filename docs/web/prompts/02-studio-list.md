# 任务 02 — 录音间列表页

> 状态：已完成

## 目标

实现录音间列表页，支持城市筛选和关键词搜索。

## 涉及文件

- `frontend/app/studios/` — 列表页路由
- `frontend/lib/api.ts` — API 客户端
- `frontend/lib/types.ts` — 类型定义

## 任务内容

1. 搜索栏（按名称/地址搜索）
2. 城市筛选 chips
3. 录音室卡片列表（封面图 + 名称 + 价格 + 地址）
4. 空状态处理
5. 加载状态

## 验收标准

1. 搜索实时过滤
2. 城市筛选正常
3. 卡片点击进入详情
4. `npm run build` 通过
