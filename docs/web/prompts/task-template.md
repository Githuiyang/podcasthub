# Web 端 Claude Code 任务模板

> 使用方式：复制此模板，填入具体任务内容，提交给 Claude Code 执行。

## 模板

```text
请基于 docs/web/[对应文档].md 完成这次 Web 端任务。

目标：
1. ...
2. ...

涉及文件：
- frontend/app/...
- backend/...

必须完成：
1. ...

验收标准：
1. ...

文档要求：
1. 更新哪些 docs/web/*.md
2. 是否同步 README / CLAUDE / PROJECT_MEMORY

输出要求：
- 修改了哪些文件
- 关键实现点
- 是否 build 通过
```

## 工作规范

每次 Web 端任务执行时：

1. 先读 `docs/web/README.md` 了解全局
2. 再读对应任务文档（02-ia / 04-data-model / 05-api-contract 等）
3. 按文档范围改代码
4. 每次改完更新文档
5. 输出改动清单和验收结果

## Web 端与小程序端分工

| 页面 | Web 端 | 小程序端 |
|---|---|---|
| 首页 | 全屏地图 + hover 卡 + 弹窗 | 发现页 + 轻量地图预览 |
| 列表 | 完整筛选搜索 | 筛选搜索 |
| 详情 | 双 Tab 弹窗 + 独立页 | 完整详情页 |
| 后台 | 完整编辑审批同步 | 轻量管理（暂缓） |
| 提交 | 飞书表单 + 变更申请 | 飞书表单入口 |
