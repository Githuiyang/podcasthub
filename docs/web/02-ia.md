## 首页 — 全屏地图

### 结构

1. **全屏高德地图** — 占满视口，marker 标记所有录音间
2. **顶部导航栏** — 四入口（首页 / 录音间 / 剪辑师 / 商务）+ "添加我的录音室"按钮 + 反馈按钮
3. **城市筛选** — 动态城市列表（从 `GET /api/studios/cities` 获取，按录音室数量降序排列），默认选中录音室数量最多的城市，按城市 fitView
4. **hover 预览卡** — 鼠标移到 marker 上弹出卡片（名称 + 地址 + 价格）
5. **双 Tab 详情弹窗** — 点击 marker 打开弹窗：
   - 信息 Tab：名称、地址、价格、开放时间、设备、预约、联系方式
   - 图片 Tab：封面图 + 作品图片
6. **录音室征集 FAB** — 右上角轻量灰色"+"浮动按钮（场景化弱入口，展开后显示"收录录音室"描边按钮）

### 数据来源

- `GET /api/studios/cities` → 城市筛选列表（动态，按录音室数量降序，返回 `{city, count}[]`）
- `GET /api/studios/list?city=xxx&size=100` → 地图 markers（带 sessionStorage 缓存）
- `GET /api/studios/detail/{id}` → 详情弹窗数据
- `GET /api/reviews/studio/{id}/count` → 评价数量

### 关键交互

- 地图自动 fitView（只基于录音棚 marker，排除交通枢纽）
- 默认选中录音室数量最多的城市（通过 `studioCities.ts` 共享逻辑动态确定）
- 城市按钮按录音室数量降序排列
- 全国概览模式：选择"全部"后展示城市聚合 marker（显示城市名+录音室数量），点击进入城市
- 城市模式：展示录音室 marker + 交通枢纽 marker，交通枢纽不参与 fitView
- hover 卡：地址/价格/开放时间/预约/联系方式归一化展示（`studioPresentation.ts`）
- 弹窗：信息 Tab 和图片 Tab 共用数据，Tab 切换不重新加载
- FAB：轻量灰色"+"按钮（场景化弱入口），hover/点击展开"收录录音室"描边按钮，进入提交录音室页
- 弹窗底部"信息有误？告诉我们"弱入口，点击打开带录音室上下文的 FeedbackModal（source=web_modal）
- 移动端：地图高度扣除顶部导航+底部 Tab（96px），桌面端仅扣除顶部导航（48px）

### 展示归一化规则

`studioPresentation.ts` 负责：
- 去除价格同义重复（`charging_method` 优先）
- 去除预约说明与 CTA 重复
- 开放时间独立展示（不从 `description` 解析）
- 联系方式合并展示

## 录音间列表页

### 结构

1. **搜索栏** — 按名称/地址搜索
2. **城市筛选** — 横向 chips（按录音室数量降序排列）
3. **卡片列表** — 封面图 + 名称 + 收费方式 + 地址

### 数据来源

- `GET /api/studios/cities` → 城市 chips
- `GET /api/studios/list?city=xxx&search=xxx` → 列表

## 独立详情页

### 结构（按阅读优先级）

1. 封面图
2. 名称 + 城市/区域 + 地址 + 标签
3. 价格（使用 `getStudioPriceText` 归一化）
4. **预约与联系**（核心决策区块，合并 CTA 按钮 + 二维码 + 预约说明 + 联系方式）
5. 开放时间
6. 设备 + 房间信息（合并为一个区块）
7. 补充介绍
8. 交通枢纽信息（`StudioTransitGrid`）
9. 作品图
10. 体验反馈（`StudioReviewSection`）

### 数据来源

- `GET /api/studios/detail/{id}` → 详情数据
- `cityTransportHubs` → 交通枢纽配置

### 信息反馈入口

- 详情页底部有"信息有误？告诉我们"弱入口（text-xs text-slate-300）
- 点击打开 FeedbackModal，自动传入 studio_id/studio_name/source（web_detail）
- 与全站产品反馈共享 FeedbackModal，有上下文时切换标题和 placeholder

### 交通信息

- 距离：直线距离（经纬度计算）
- 打车时间：经验估算
- 枢纽数据：`cityTransportHubs` 注册表，已覆盖 9 城市
- 新增城市时只需在注册表追加一条

## 管理后台

### 认证

- `POST /api/auth/admin/login` → 密码验证 → HMAC token
- `AdminAuthGuard` 组件包裹 `/admin/*` 路由
- 密码存储在 Vercel 环境变量 `ADMIN_PASSWORD`

### 录音室编辑页

- 表格展示所有录音室（支持城市筛选）
- 行内编辑：联系方式、收费方式、预约信息等
- 软删除（`is_active=false`）
- 图片上传（Supabase Storage）
- 预约二维码上传

### 飞书同步页

- 拉取飞书结果表数据
- 与线上数据比对（diff）
- 确认后同步上线（新增/更新/软删除）

### 变更审批页

- 查看待审批变更申请
- 预览 diff
- 批准/拒绝
- 批准后自动写入 studios 表

## 剪辑师模块

### 列表页（人才墙）

- 路由：`/editors`
- 导航栏"剪辑师"一级入口
- 4 列人物卡（居中布局：头像 + 姓名 + 类型标签 + 状态标签 + 简介 + 代表作 + 报价）
- slate 统一色系
- 搜索栏
- 空态引导 + 报名入口
- 标题区含"商务合作 →"二级链接（指向 `/business`）

### 详情页（人物主页）

- 路由：`/editors/[id]`
- 居中布局（max-w-2xl），border-b border-slate-100 分隔各区块
- 阅读顺序：头像+姓名+类型+状态+简介+标签 → 统计卡（年经验/每期价格/作品数）→ 擅长方向 → 专业能力（技能/软件/专长）→ 过往作品 → 合作评价 → 报价 → 联系方式
- slate 统一色系
- 使用 `ContactInfo`、`TagList` 共享组件
