# 01 — Web 端范围定义

> 状态：已冻结
> 最后更新：2026-04-15

## 已完成范围

### 核心展示

- 全屏地图首页（高德 JS API v2.0）
- 录音间列表页（搜索 + 城市筛选）
- 独立详情页（信息 + 图片）
- 录音室征集页（飞书表单入口）
- 反馈弹窗（飞书 Webhook）

### 管理与同步

- 管理后台（密码认证 + 录音室编辑 + 软删除）
- 飞书同步（结果表拉取 + diff + 同步上线）
- 变更申请（审批 + diff + 同步上线）

### 扩展模块

- 剪辑师模块（人才墙 + 人物主页 + 作品展示）
- 商务模块（人才墙 + 人物主页）
- 录音室评价 API（后端已实现）

## 暂不做的范围

- 复杂评论社区
- 用户注册 / 登录系统
- 支付 / 订阅
- 多语言
- 实时 WebSocket 通信
- 复杂权限系统（RBAC）
- 移动端 App（由小程序承担）

## 做与不做原则

| 做 | 不做 |
|---|---|
| 录音室发现与选择 | 复杂社区系统 |
| 轻量提交与审核 | 自建表单引擎 |
| 飞书同步链路 | 实时多人协作 |
| 人物主页展示 | 社交网络功能 |
| 基础分析与埋点 | 复杂广告追踪 |
