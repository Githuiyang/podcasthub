## 页面分工

| 页面 | 定位 | 核心任务 |
|---|---|---|
| 录音室 | TabBar 主入口 | 搜索、城市筛选、浏览录音室卡片、提交/反馈入口 |
| 创作者 | TabBar 第二入口 | 分段切换剪辑师/制作人、搜索、浏览创作者卡片 |
| 录音室详情页 | 决策与判断 | 查看完整信息、确认预约、了解交通、做出决定 |
| 创作者详情页 | 了解与联系 | 查看创作者资料、判断是否合作、获取联系方式 |

> **重要**：录音室 Tab 是浏览与筛选的主入口，创作者 Tab 是发现人的入口。两个 Tab 各自独立，形成"找场地 + 找人"双入口。

## 各页面区块规划

### 录音室页（已实现）— TabBar 主入口

录音室页定位为**搜索、筛选、浏览录音室的核心页面**，同时承载提交/反馈入口。

结构自上而下：
1. **搜索栏** — 圆角搜索框，支持按名称/地址实时搜索，带清除按钮
2. **城市筛选** — 横向可滚动的城市 chip 组（全部 + 9 个城市），点击切换，支持反选
3. **结果摘要** — 当前城市 + 总数（如 "上海 · 9 间录音室"）
4. **录音室卡片列表** — 每张卡片含封面图（或首字占位）+ 名称 + 收费方式 + 容纳人数 + 地址
5. **底部操作按钮** — "提交录音室"（主按钮，深色填充）+ "意见反馈"（次按钮，描边样式）

数据来源：
- `GET /api/studios/cities` -> 城市列表
- `GET /api/studios/list?city=xxx&search=xxx&size=200` -> 录音室列表

交互：
- 城市筛选 -> 重新请求 API，selectedCity 变化触发 loadStudios
- 搜索框 -> 实时输入触发 loadStudios（searchKeyword 变化）
- 录音室卡片 -> `navigateTo /pages/studio-detail/index?id=xxx`
- 空状态 -> 区分"城市无数据"和"搜索无结果"，搜索无结果时提供"清除搜索"按钮
- 加载失败 -> 错误提示 + 重新加载按钮
- 加载中 -> 5 张骨架卡片
- "提交录音室" -> `navigateTo /pages/submit-studio/index`
- "意见反馈" -> `navigateTo /pages/feedback/index`

样式：
- 全屏 flex 布局，搜索栏和城市筛选固定在顶部，卡片列表可滚动
- 城市选中态为深色胶囊（#111827），未选中为浅灰（#f3f4f6）
- 卡片左图右文
- 价格标签绿色背景（#f0fdf4），容量标签灰色背景（#f3f4f6）
- 底部按钮区：主按钮深色填充白字，次按钮描边样式

### 创作者页（已实现）— TabBar 第二入口

创作者页定位为**发现剪辑师和制作人**的入口，通过分段控件切换两种角色。

结构自上而下：
1. **分段控件（Segment Control）** — "剪辑师" / "制作人" 两个选项卡，点击切换
2. **搜索栏** — 圆角搜索框，支持按名称实时搜索，带清除按钮
3. **创作者卡片列表** — 每张卡片含头像（或首字占位）+ 名称 + 标签芯片 + 简介
4. **空状态** — "正在入驻中，敬请期待"友好提示 + 图标

数据来源：
- `GET /api/editors/list?search=xxx&page=1&size=20` -> 剪辑师列表
- `GET /api/business/list?search=xxx&page=1&size=20` -> 制作人列表

交互：
- 分段切换 -> 切换 activeTab，重新加载对应列表
- 搜索框 -> 实时输入触发搜索
- 创作者卡片 -> `navigateTo /pages/creator-detail/index?id=xxx&kind=editor|business`
- 空状态 -> 显示友好空状态文案（当前 editors 和 business_contacts 表均为 0 条记录）
- 加载中 -> 骨架卡片
- 加载失败 -> 错误提示 + 重试

样式：
- 分段控件居中，选中项深色填充白字，未选中浅灰底深字
- 卡片水平布局：左侧圆形头像 + 右侧信息（名称 + 标签 + 简介）
- 标签芯片：浅色背景胶囊样式
- 空状态：居中图标 + 文案，轻量不压迫

### 创作者详情页（已实现）

创作者详情页定位为**了解创作者并判断是否合作**，通过 `kind` 参数条件渲染不同内容。

结构自上而下（条件渲染）：
1. **共享头部** — 居中头像 + 名称 + 标签芯片 + 简介
2. **剪辑师专属区块**（kind=editor）：
   - 擅长技能标签列表
   - 作品展示
   - 报价信息
   - 合作评价
3. **制作人专属区块**（kind=business）：
   - 行业领域
   - 服务类型
   - 联系方式

数据来源：
- `GET /api/editors/detail/{id}` -> 剪辑师完整信息（kind=editor）
- `GET /api/business/detail/{id}` -> 制作人完整信息（kind=business）

交互：
- 动态标题 -> `Taro.setNavigationBarTitle({ title: creator.name })`
- 复制联系方式 -> `Taro.setClipboardData`
- 加载中 -> 骨架屏
- 加载失败 -> 错误提示 + 重新加载按钮

### 录音室详情页（已实现）

详情页定位为**决策页**，让用户快速判断"这间录音室值不值得去"。

结构自上而下（条件渲染，仅在有数据时展示对应区块）：
1. **头部** — 名称 + 标签芯片（tags）+ 容纳人数 + 房间数
2. **封面图** — 宽度自适应（widthFix）
3. **地址** — 城市+区划+地址拼接，点击可复制
4. **价格** — 收费方式（charging_method）为主，fallback 到时价/天价，附价格备注
5. **开放时间** — open_hours 文字展示
6. **预约方式** — booking_note 文字 + booking_qr_image 二维码图片 + booking_url 复制链接按钮
7. **设备** — equipment 标签芯片列表
8. **介绍** — description 文字
9. **联系方式** — 联系人 + 电话（一键拨号，失败自动复制号码）+ 微信（复制）+ 联系方式（复制）
10. **图片** — portfolio_images 横向滚动，点击全屏预览（Taro.previewImage）

数据来源：
- `GET /api/studios/detail/{id}` -> Studio 完整信息

交互：
- 动态标题 -> `Taro.setNavigationBarTitle({ title: studio.name })`
- 复制地址/微信号/预约链接 -> `Taro.setClipboardData`
- 一键拨号 -> `Taro.makePhoneCall`（失败 fallback 复制号码）
- 图片预览 -> `Taro.previewImage`（支持左右滑动）
- 加载中 -> 骨架屏
- 加载失败 -> 错误提示 + 重新加载按钮

> 注意：当前详情页未包含交通枢纽信息（Web 端有此功能），小程序端暂不实现。评价功能也暂未实现。
