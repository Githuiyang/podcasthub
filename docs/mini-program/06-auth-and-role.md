# 06 — 角色与权限

> 状态：骨架版

## 两种角色

| 角色 | 说明 | 能力 |
|---|---|---|
| 游客 | 默认状态 | 浏览录音室、搜索、查看详情、提交反馈 |
| 管理员 | 密码登录后 | 编辑录音室、软删除、查看后台 |

## 认证方式

- 与 Web 端一致：`POST /api/auth/admin/login`，密码验证后返回 HMAC token
- Token 存储在小程序 Storage 中
- 管理员页面进入前检查 token 有效性

## 权限控制

- 游客态：所有浏览类页面正常访问，管理页面不可见
- 管理员态：额外显示管理入口，可进入后台页面
- 不做微信登录，不做用户注册，保持最简
