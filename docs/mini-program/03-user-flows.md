## 普通访客流程

### 流程 A：从录音室 Tab 发现
1. 进入小程序 -> 默认打开"录音室"Tab（主入口）
2. 看到搜索栏 + 城市筛选 chips + 录音室卡片列表
3. 点击城市 chip -> 切换城市筛选，重新加载录音室列表
4. 在搜索框输入关键词 -> 实时过滤录音室（按名称/地址）
5. 点击录音室卡片 -> 进入详情页
6. 滚动到底部 -> 看到"提交录音室"（主按钮）+ "意见反馈"（次按钮）
7. 空结果时点击"清除搜索" -> 恢复全部列表

### 流程 B：详情页决策
1. 从录音室 Tab 卡片进入详情页
2. 查看名称、标签、地址、价格、开放时间、设备、介绍
3. 点击地址 -> 复制到剪贴板
4. 点击电话 -> 一键拨号（失败时自动复制号码）
5. 点击微信 -> 复制微信号
6. 点击预约链接按钮 -> 复制预约链接到剪贴板
7. 查看预约二维码图片 -> 长按或截图保存
8. 点击图片 -> 全屏预览（Taro.previewImage），可左右滑动

### 流程 C：浏览创作者
1. 底部 Tab 切换到"创作者" -> 进入创作者页
2. 看到分段控件（剪辑师 / 制作人）+ 搜索栏 + 创作者卡片列表
3. 默认展示"剪辑师"Tab，列表为空时显示"正在入驻中，敬请期待"
4. 点击"制作人"分段 -> 切换到制作人列表
5. 在搜索框输入关键词 -> 实时搜索创作者
6. 点击创作者卡片 -> 进入创作者详情页（`?id=xxx&kind=editor|business`）
7. 详情页查看头像、名称、标签、简介，以及对应角色的专属信息
8. 点击联系方式 -> 复制到剪贴板

### 流程 D：反馈
1. 录音室 Tab 滚动到底部 -> 点击"意见反馈"按钮
2. 进入反馈页 -> 当前为占位版，显示"功能开发中，敬请期待"

## 录音室主理人流程

1. 录音室 Tab 滚动到底部 -> 看到"提交录音室"按钮
2. 点击"提交录音室" -> 进入提交页
3. 看到 4 步流程说明
4. 点击"复制问卷链接" -> 飞书表单 URL 复制到剪贴板
5. 在浏览器中打开表单并填写
6. 提交后等待审核上线
