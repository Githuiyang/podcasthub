# 08 — 设计系统

> 状态：已更新（新增创作者页视觉原则）
> 最后更新：2026-04-16

## 设计原则

1. **轻量优先**：每个页面只承担一个主任务
2. **信息清晰**：录音室名称、地址、价格为最高优先级；创作者名称、标签为最高优先级
3. **与 Web 端视觉统一**：颜色、间距、字体风格对齐
4. **双入口清晰分工：录音室 + 创作者**：录音室 Tab 负责"找场地"，创作者 Tab 负责"找人"，两个入口各司其职

## 录音室页视觉原则

- 搜索栏圆角输入框，右侧清除按钮
- 城市筛选横向排列，选中态深色填充白字，未选浅灰底深字
- 录音室卡片左图右文：封面图（或首字占位）+ 名称 + 价格 badge + 容纳人数 + 地址
- 价格标签绿色背景（#f0fdf4），容量标签灰色背景（#f3f4f6）
- 底部操作区：主按钮（深色填充白字）"提交录音室" + 次按钮（描边样式）"意见反馈"
- 空状态区分"城市无数据"和"搜索无结果"
- 加载中显示骨架卡片

## 创作者页视觉原则

- 分段控件居中展示，选中项深色填充白字（与城市筛选风格统一），未选中浅灰底深字
- 搜索栏与录音室页风格一致
- 创作者卡片水平布局：左侧圆形头像（80rpx）+ 右侧信息（名称 + 标签芯片 + 简介）
- 标签芯片：浅色背景胶囊样式（#f3f4f6 背景 + #374151 文字）
- 空状态：居中图标 + "正在入驻中，敬请期待"文案，轻量不压迫
- 加载中显示骨架卡片

## 创作者详情页视觉原则

- 头部居中布局：圆形头像（大尺寸）+ 名称 + 标签芯片 + 简介
- 条件渲染区块：根据 kind 参数（editor/business）展示不同专属内容
- 剪辑师区块：擅长技能标签列表 + 作品展示 + 报价信息 + 合作评价
- 制作人区块：行业领域 + 服务类型 + 联系方式
- 区块间使用分割线或间距分隔，保持清晰层次
- 加载中显示骨架屏

## 色彩

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 | `#111827` | 标题、主要文字 |
| 强调色 | `#f59e0b` | CTA、录音室标记（与 Web 端一致） |
| 辅助灰 | `#64748b` | 次要文字 |
| 背景 | `#f9fafb` | 页面底色 |
| 卡片白 | `#ffffff` | 卡片背景 |

## 间距

- 页面内边距：`32px`（对应 16rpx x 2）
- 卡片间距：`24px`
- 卡片内边距：`32px`
- 区块间距：`40px`

## 圆角

- 卡片：`24px`
- 按钮：`16px`
- 标签：`999px`（胶囊）

| 卡片标题 | 32px |
| 正文 | 28px |
| 辅助文字 | 24px |
| 标签 | 22px |
