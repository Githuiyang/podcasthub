# PodcastHub 小程序项目总览

这是 PodcastHub 小程序扩展的总索引文档。
后续所有的小程序规划、任务拆分、Claude Code 提示词、页面结构、接口设计和验收标准，都以这里的说明为准。

## 文档用途

这个目录不是"随手记笔记"的地方，而是小程序项目的**单一事实来源（Single Source of Truth）**：

- 先在这里定义项目边界和目标
- 再从这里拆分页面、功能、接口、权限、同步、发布
- 最后把这里的内容转成 Claude Code 可执行的任务提示词

如果后续需求变化，优先更新这里，再生成任务提示词，不要直接跳进代码实现。

## 现有仓库背景

PodcastHub 当前已有：

- 前端 Web：Next.js + React
- 后端：FastAPI + SQLAlchemy
- 数据库：Supabase Postgres
- 存储：Supabase Storage
- 录音室展示主站、详情页、后台、提交页、反馈页、变更申请与同步能力

小程序不是重做一套独立业务，而是把现有能力延伸到微信生态中，形成更轻、更易传播的移动端入口。

## 小程序核心定位

小程序的第一目标不是"把 Web 站完整搬过去"，而是：

1. 让用户更快找到录音室
2. 让用户发现创作者（剪辑师/制作人）
3. 让录音室主理人更容易提交资料
4. 让用户更方便反馈体验和纠错
5. 让管理员能够在移动端或轻量流程中完成部分审核与同步工作

小程序的角色会比 Web 更轻：

- Web 站：完整展示、编辑、审核、同步、管理
- 小程序端：轻量浏览、轻量提交、轻量反馈、轻量校验

## 小程序信息架构

建议页面结构如下：

- 录音室（TabBar 主入口）
- 创作者（TabBar 第二入口）
- 录音室详情
- 创作者详情
- 提交录音室
- 反馈
- 管理员登录
- 管理员页

剪辑师与制作人通过"创作者"Tab 统一入口，用分段控件（segment control）切换，不打断录音室主线。
