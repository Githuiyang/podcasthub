## 验收标准

### Phase 1（骨架）
- 页面路由可达
- TabBar 正常（录音室 + 创作者）
- 基础配置完整

### Phase 2（核心浏览）
- 录音室 Tab 展示搜索栏 + 城市筛选 + 卡片列表
- 录音室 Tab 城市筛选切换正常，列表刷新
- 录音室 Tab 搜索实时过滤正常
- 录音室 Tab 底部提交/反馈按钮可用
- 录音室详情页展示完整信息（名称、标签、地址、价格、开放时间、预约、设备、介绍、联系方式、图片）

### Phase 2.5（创作者浏览）
- 创作者 Tab 展示分段控件（剪辑师/制作人）
- 创作者 Tab 分段切换加载对应列表
- 创作者 Tab 搜索正常
- 创作者空状态展示"正在入驻中"友好提示
- 创作者详情页加载正常，根据 kind 参数条件渲染
- 创作者详情页共享头部展示正确（头像+名称+标签+简介）

### Phase 3（提交与反馈）
- 提交页引导文案 + 复制飞书表单链接
- 反馈页占位展示（功能开发中）

### Phase 4（管理）
- 管理员登录 -> token 存储 -> 后台页面访问
- 编辑/删除录音室
