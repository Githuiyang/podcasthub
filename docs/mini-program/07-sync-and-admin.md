# 07 — 同步与审核工作流

> 状态：骨架版

## 现有工作流（Web 端已实现）

```text
飞书问卷收集 → 飞书结果表整理 → 人工确认 diff → 同步线上
```

## 小程序中的同步能力

第一期小程序暂不实现完整的飞书同步 diff 页面（该能力保留在 Web 端）。小程序管理端只做：

- 查看录音室列表
- 编辑基本信息
- 软删除

复杂的飞书同步、变更申请审批等流程继续在 Web 后台完成。
